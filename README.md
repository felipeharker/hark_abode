# hark_abode

House projects.

- `exterior_lighting/` - roof-edge lighting linework, linear-footage takeoff, light runs from the two outlets, and product sheet (Rhino + PDF).
- `home_survey/` - source material: survey plat and front-of-house photos. Local only.
- `home_records/` - public records on the design and construction. Local only.

## What is published

The GitHub repo holds only the lighting documents: this file, `exterior_lighting/README.md` and the three PDFs in `exterior_lighting/`. `.gitignore` ignores everything else, so `home_survey/`, `home_records/`, the Rhino model and the scripts stay on this computer. Nothing published carries the street address; keep it that way.
